📌 คำแนะนำการเชื่อมโยงข้อมูลจริงจาก Tableau (sheet16)

วิธีนำข้อมูลตารางจากแดชบอร์ดกรมควบคุมโรคมาแสดงผลในแผนที่นี้
  1. เปิดลิงก์ Tableau กองระบาดวิทยา (sheet16) บนเบราว์เซอร์ของคุณ
  2. กดปุ่ม Download (ดาวน์โหลด) มุมขวาบนของตาราง เลือก Crosstab (CSV / Excel) หรือกดคัดลอกตาราง

  4. กดปุ่ม "💾 บันทึกไฟล์ HTML พร้อมข้อมูล" เพื่อดาวน์โหลดไฟล์ HTML ฉบับสมบูรณ์ที่มีข้อมูลจริงฝังอยู่ในตัวไฟล์
